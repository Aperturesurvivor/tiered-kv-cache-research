# Release scope and limitations

Source: private study repository at 90826838fae95c3f557629bac47c85282b945fc0. The paper cites the completed-study snapshot 735155ba7db1828ffb7370c2ae354cb008a6908f. These are provenance identifiers, not public release commits.

The release retains selected reports and structured evidence for the 28 cited artifacts, and the observations needed by `paper/verify_results.py` to recompute the four principal tables and selected ablation values. It does not include the full original repository, all original evidence files, large private backup payloads, model weights, runtime state or deployment tooling. The original observer archive was reduced to its unmodified sample member. Operational identifiers in one provenance document were redacted. See `REDACTIONS.json` for hashes and omitted files. `verified-results.json` has been updated for these changes; it is a public-package receipt, not the byte-identical original receipt.

The evidence map points to the v1.0.0 release paths. Directory contents are subsets of original run folders; reports, hashes, and selected observations do not independently reconstruct omitted tensors, full replay, complete original runs, or every secondary claim. The historical study ledger is omitted and its link is replaced with this scope disclosure. No new model experiments were performed. AI-mediated reviews are not independent human replication. License terms for external models, data, publications, and other third-party materials remain with their owners.

LongBench `gov_report` raw summary fixtures, token sequences, and samples are excluded; pilot source/reference fields are redacted, while predictions and recorded scores remain. These summary claims are report-level evidence and cannot be independently rescored from this package. The three original question-logit arrays are included with a checksum manifest and a separate NumPy comparison script. Neither that check nor the table validator runs inference. The source code and configuration are provided as historical reference; complete historical test and execution environments are not included.
